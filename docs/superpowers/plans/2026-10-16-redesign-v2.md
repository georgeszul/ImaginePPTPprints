# Redesign v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild every visible part of the Imagine PPTP Prints site in the "print studio editorial" design on branch `redesign-v2`, keeping only the photos, logo, business facts and tested plumbing.

**Architecture:**
- The new visible layer (layout `Page.astro`, new components, new styles, new wording) is built next to the old one, so the site builds and passes checks after every task.
- Each view switches from the old `Base.astro` to the new `Page.astro` in its own task, and Task 9 deletes the old layer.
- New component names never collide with old ones.
- Work runs in three waves:
  1. the foundation, in the main session;
  2. six page tasks in parallel, each agent in its own git worktree;
  3. cleanup, review and final checks, in the main session.

**Tech Stack:**
- Astro 5.18.2 (static output)
- Fontsource: Bricolage Grotesque, Instrument Sans and IBM Plex Mono
- `node --test` for unit tests
- playwright-core from the global `@playwright/cli` install, driving system Chrome, for QA

**Spec:** `docs/superpowers/specs/2026-10-15-redesign-v2-design.md`

## Review Focus

These five failure modes are the most likely to bite a real visitor. Each one gets a check in the task that owns the code:

1. **Longer Spanish text** overflows or clips at 320 px (menu, buttons, hero headline, contact buttons). The QA matrix in Task 1 runs every Spanish page at 320 px and fails on horizontal overflow or any element wider than the viewport.
2. **No JavaScript.** The menu links must stay reachable, Work must show every photo, the calculator must show its default estimate, and the form must still submit. Covered by `checks/chrome.mjs` (Task 2), `checks/services.mjs` (Task 4) and `checks/work.mjs` (Task 5).
3. **Portrait and landscape photos** in fixed frames must never stretch or leave gaps. The Task 1 matrix fails when a `figure.fig img` does not fill its frame with `object-fit: cover`.
4. **Netlify form contract.** The built contact page must keep the form name `quote`, `data-netlify`, the honeypot, multipart encoding, the thanks-page action and every field name. Covered by `checks/contact.mjs` (Task 7), which reads `dist/`.
5. **Focus hidden behind the sticky header or the contact buttons** while tabbing through `/contact/` at 320×568 and 1280×800. Covered by `checks/chrome.mjs` (Task 2) and re-run after Task 7.

`src/lib/contrast.js`:

```js
// WCAG 2 contrast for the design tokens (spec: Color tokens). Used by contrast.test.js.
const channel = (v) => {
  v /= 255;
  return v <= 0.04045 ? v / 12.92 : ((v + 0.055) / 1.055) ** 2.4;
};

export function luminance(hex) {
  const n = parseInt(hex.slice(1), 16);
  const [r, g, b] = [n >> 16, (n >> 8) & 255, n & 255].map(channel);
  return 0.2126 * r + 0.7152 * g + 0.0722 * b;
}

export function ratio(a, b) {
  const [hi, lo] = [luminance(a), luminance(b)].sort((x, y) => y - x);
  return (hi + 0.05) / (lo + 0.05);
}

/** Hex tokens per theme: the block holding :root[data-theme='light'] and the one holding :root[data-theme='dark']. */
export function readThemes(css) {
  const block = (selector) => {
    const at = css.indexOf(selector);
    if (at === -1) return {};
    const body = css.slice(css.indexOf('{', at) + 1, css.indexOf('}', at));
    return Object.fromEntries([...body.matchAll(/--([\w-]+):\s*(#[0-9a-fA-F]{6})/g)].map((m) => [m[1], m[2]]));
  };
  return { light: block(":root[data-theme='light']"), dark: block(":root[data-theme='dark']") };
}
```

```js
// Netlify form contract in the built contact pages (dist/), both languages.
import { readFileSync } from 'node:fs';
import { join } from 'node:path';

export default async function ({ fail, repo }) {
  for (const file of ['dist/contact/index.html', 'dist/es/contacto/index.html']) {
    const html = readFileSync(join(repo, file), 'utf8');
    const form = html.match(/<form[^>]*name="quote"[^>]*>/)?.[0] ?? '';
    for (const attr of ['data-netlify="true"', 'netlify-honeypot="bot-field"', 'enctype="multipart/form-data"', 'method="POST"']) {
      if (!form.includes(attr)) fail(`${file}: quote form missing ${attr}`);
    }
    if (!/action="\/(es\/gracias|thanks)\/"/.test(form)) fail(`${file}: quote form action is not the thanks page`);
    const names = ['form-name', 'lang', 'bot-field', 'name', 'email', 'phone', 'contact_method', 'service', 'shirt_type', 'shirt_sizes', 'shirt_qty', 'shirt_colors', 'hoodie_type', 'hoodie_sizes', 'hoodie_qty', 'hoodie_colors', 'hat_type', 'hat_qty', 'hat_colors', 'banner_size', 'banner_material', 'card_size', 'card_finish', 'card_qty', 'other_qty', 'other_colors', 'deadline', 'design_file', 'reference_image', 'message', 'spanish'];
    const missing = names.filter((n) => !html.includes(`name="${n}"`));
    if (missing.length) fail(`${file}: quote form missing fields ${missing.join(', ')}`);
  }
}
```
